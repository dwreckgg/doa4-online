# The host tests the Linux job compiles and runs (tools/run_host_tests_posix.py reads this file; the job is
# .github/workflows/linux-build.yml). Every tests/host/run_<name>_test.bat is on exactly one line here:
#
#   <name> | <sources, space separated, relative to the repository root> | <extra flags>     the test runs
#   !<name> | <reason>                                                                     the test is left out
#
# <name> is the middle part of run_<name>_test.bat. A run line is compiled in the repository root with
#   <cxx> -std=c++23 -O2 <flags> <sources> -o <tmp>/<name>
# and its program is started in tests/host. In the flags, {SDK} stands for the SDK folder (REXSDK_DIR).
#
# A test has a run line when its sources, followed through their local #include "..." lines, reach no Windows header
# outside a block compiled only on Windows (#ifdef _WIN32, #if defined(_WIN32), the #else of #ifndef _WIN32), and its
# .bat is one clang-cl line that names only files of this repository. Its sources are that line's .cpp files. Its flags
# are that line's /D options as -D, with /D_MSVC_STL_HARDENING=1 as -D_GLIBCXX_ASSERTIONS and the Windows-only
# /D_WIN32_WINNT, /DWIN32_LEAN_AND_MEAN and /DNOMINMAX dropped, and a repository include folder as -I <folder>.
# tests/tools/test_release_tools.py checks all of this against the .bat files and the sources, so a line here that
# no longer matches its .bat fails that suite.
#
# A left-out reason starts with one of:
#   windows header: <file>:<line> <header>   the first Windows header the sources reach outside such a block
#   needs the SDK: <what the .bat names>     the .bat names %REXSDK_DIR% or a folder outside the repository
#   needs game files: <what>
#   other: <why>                             (a multi-step build: compile loops, object and link steps, a Python step)
#
# Notes:
# - The Linux job is x86-64 only: cpu_info's non-Windows Read() uses <cpuid.h>, and there is no arm64 path.
# - cpu_info counts cores from /sys/devices/system/cpu, with `logical` from sysconf(_SC_NPROCESSORS_ONLN).
# - updater_refusal's check 7 needs glibc 2.28 or newer, for renameat2.
# - updater_refusal is the one run line that takes a header from the SDK: src/doa4_updater.cpp includes
#   "picosha2/picosha2.h" when it is not built for Windows, so its line adds -pthread -I {SDK}/thirdparty.
# - np_transport's .bat builds with /std:c++20, and also compiles src/net/np_upnp.cpp alone as a build check; the
#   Linux line uses -std=c++23 like every other and has no such second compile.
